# OMA-BS 0.7.1 — panel polish

- Consistent subtle borders and rounded corners on native buttons, dropdowns,
  input fields, gallery cards, dock tabs, preview areas, and editor tracks.
- Capture, audio, webcam, and expanded input settings grouped in padded cards.
- Matching oval Record and shorter Stream buttons on the same row.
- Removed the redundant Close webcam now button. The existing webcam toggle
  and normal window close still work; capture cleanup remains automatic.
- Transparent scrollbar tracks with slim theme-colored handles that fade away
  when idle. Handles appear only when content overflows and scrolling/hovering
  activates them; the footer remains fixed and visible.

This update changes the native interface only. The recording/streaming engine,
saved destinations, and optional browser studio retain their 0.7.0 behavior.
